# STRICT RULE: NO AI SLOP (АНТИ-ИИ-СЛОП)

При любой генерации разметки, стилей, компонентов, виджетов или страниц платформы **СТРОЖАЙШЕ ЗАПРЕЩЕНО**:

1. **Неоновое сияние (`box-shadow: 0 0 ...`, `text-shadow: 0 0 ...`)**:
   - Запрещены любые размытые цветные неоновые ореолы вокруг элементов.
   - Использовать только естественные затемняющие тени `rgba(0, 0, 0, 0.4)` и четкие тонкие рамки `1px solid rgba(255, 255, 255, 0.08)`.

2. **Мигающие / пульсирующие точки (`pulse`, `liveBlink`, `pulseDot`)**:
   - Точки статуса обязаны быть статичными, четкими точками 6px без бесконечных пульсаций и размытия.

3. **Эмодзи в интерфейсных элементах**:
   - Никаких эмодзи в кнопках, табах, заголовках, опциях или таблицах лидеров.
   - Использовать только монохромные SVG-векторы или профессиональную моноширинную типографику.

4. **Псевдо-маркетинговые бейджи-клише**:
   - Никаких «Киллер-фича», «Zero-Knowledge», «VS Battle», «Признание 🥇».
   - Только информативные, спокойные названия на русском или казахском языке.

5. **Бутафорские анимации**:
   - Никаких лазерных лучей сканирования по QR-коду, прыгающих корон или дрожания карточек.
   - Только функциональная анимация состояний (transition на 150-250ms, плавный cubic-bezier).

# Спецификация платформы TengeAlert

**TengeAlert** — независимое программное обеспечение для автоматизации оповещений стримеров на основе локальных системных уведомлений.

> [!NOTE]  
> **Юридический статус (Clean Room):**  
> TengeAlert не использует закрытые API и не аффилирован с АО «Kaspi Bank», Halyk Bank или любыми другими финансовыми организациями. Программа с согласия пользователя обрабатывает стандартные уведомления операционной системы (Android NotificationListenerService / Windows UserNotificationListener), не хранит и не передает финансовые реквизиты, номера счетов и балансы.

---

## 1. Универсальный формат событий (TengeAlert Event Payload)

Все входящие события транслируются в единый нейтральный формат:

```json
{
  "id": "ta_9f81a2c4e5",
  "source_type": "transfer",
  "source_label": "Мгновенный перевод",
  "amount": 5000,
  "currency": "KZT",
  "sender": "Азамат Б.",
  "message": "Удачи на стриме!",
  "timestamp": "2026-09-14T11:15:00.000Z",
  "theme": "cyber_emerald"
}
```

---

## 2. Стили и кастомизация виджетов

Поддерживаемые визуальные темы TengeAlert:
1. `cyber_emerald` — Фирменный стиль: неоновый изумруд (`#00f5a0`) + глубокий обсидиан + бирюзовый акцент.
2. `royal_gold` — Премиальное золото (`#ffd15c`) + янтарное сияние + алмазные частицы.
3. `qazaq_neon` — Степной киберпанк: ультрафиолет (`#8b5cf6`) + неоновый бирюзовый с элементами орнамента.
4. `minimal_glass` — Чистое матовое стекло, монохромная эстетика, типографика в стиле Linear/Apple.

Поддерживаемые звуковые пресеты (синтезируются через Web Audio API):
- `coin` — Звонкие золотые монеты.
- `crystal` — Кристальный перелив.
- `level_up` — Игровой аркадный аккорд повышения уровня.
- `jackpot` — Каскадный выигрышный перезвон.
